# Raio-X Corpo Humano

App educativa: câmara ou foto, animação de scanner, lente de raio-X e zoom sobre 10 sistemas e 61 órgãos do corpo humano.

Abrir: https://zingarelhos.github.io/raio-x/

As fotos e os dados da pessoa ficam só no aparelho (browser) e nunca são enviados.

## Créditos das ilustrações

- Esqueleto: "Human skeleton front - no labels.svg", de Mikael Häggström, baseado em Mariana Ruiz Villarreal (LadyofHats). Domínio público. Wikimedia Commons.
- Sistema respiratório: "Respiratory system complete en.svg", de Mariana Ruiz Villarreal (LadyofHats). Domínio público. Wikimedia Commons.
- Sistema digestivo: "Digestive system diagram edit.svg", de Mariana Ruiz Villarreal (LadyofHats), com edições de Joaquim Alves Gaspar e Jmarchn. Domínio público. Wikimedia Commons.

Os restantes desenhos são simplificados e os números são médias aproximadas, apenas para fins educativos.
